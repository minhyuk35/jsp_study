================================================================
  HATSHOP 설치 가이드
================================================================
  접속 주소: http://localhost:8080/hatshop
================================================================

[ 필수 환경 ]
  - JDK 17 이상  (없으면 STEP 0 참고)
  - MySQL 8.x    (없으면 MySQL 설치 후 진행)

----------------------------------------------------------------
  STEP 0 — JDK 설치 (이미 있으면 건너뜀)
----------------------------------------------------------------
  https://adoptium.net 에서 JDK 21 다운로드 후 설치
  (설치 시 "Set JAVA_HOME" 옵션 체크 권장)

----------------------------------------------------------------
  STEP 1 — MySQL DB 초기화 (최초 1회만)
----------------------------------------------------------------
  MySQL 접속 후 아래 순서로 실행:

    mysql -u root -p < sql\hatshop.sql
    mysql -u root -p hatshop < sql\sample_data.sql

  ※ root 비밀번호가 'hatshop1234' 가 아닌 경우:
     tomcat\webapps\hatshop.war 를 .zip 으로 열어
     WEB-INF\classes\db.properties 에서 비밀번호 수정

  ※ 관리자 계정 (비밀번호: admin1234):
     INSERT INTO member (member_id, member_pw, member_name, email, grade)
     VALUES ('admin',
             '$2a$10$N.8v5eFNMp/xYFpuAADnZusQrLRiyiv4WX2VVlwnCjVuBPizZ5OKG',
             '관리자', 'admin@hatshop.com', 'ADMIN');

----------------------------------------------------------------
  STEP 2 — 서버 시작
----------------------------------------------------------------
  start.bat 더블클릭
  → 브라우저에서 http://localhost:8080/hatshop 접속

  서버 종료:
  stop.bat 더블클릭  (또는 터미널 창 닫기)

----------------------------------------------------------------
  폴더 구조
----------------------------------------------------------------
  hatshop-server\
    start.bat          ← 서버 시작
    stop.bat           ← 서버 종료
    SETUP.txt          ← 이 파일
    sql\
      hatshop.sql      ← DB 스키마
      sample_data.sql  ← 상품 200개 샘플 데이터
    tomcat\            ← Apache Tomcat 9.0
      webapps\
        hatshop.war    ← HatShop 애플리케이션

================================================================
